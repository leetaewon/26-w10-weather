# 실시간 날씨·미세먼지 대시보드 (`26-w10-weather`)

전 세계 기상 관측 네트워크 API(Open-Meteo)와 연동하여 대한민국 주요 도시 및 전 세계 도시의 실시간 날씨, 미세먼지 수치, 24시간 시간별 기온 변화, 7일간 주간 예보를 직관적으로 제공하는 반응형 웹 대시보드입니다.

---

## 🌤️ 소개

- **실시간 날씨 & 미세먼지 동시 조회**: 현재 기온, 체감온도, 습도, 풍속, 강수량과 함께 대한민국 환경부 기준(좋음/보통/나쁨/매우나쁨)에 맞춘 미세먼지(PM10) 및 초미세먼지(PM2.5) 컬러 뱃지 제공
- **24시간 기온 SVG 차트**: 무거운 외부 라이브러리 없이 순수 SVG로 구현한 경량 꺾은선 차트를 통해 오늘 하루 시간대별 기온 변화 시각화
- **7일간 주간 일기예보**: 향후 일주일간의 날씨 상태 아이콘, 강수 확률(%), 최저~최고 기온 컬러 게이지 바 제공
- **400ms 디바운스 도시 검색**: Geocoding API를 연동하여 서울, 부산뿐만 아니라 도쿄, 뉴욕, 파리 등 전 세계 도시 검색 및 드롭다운 지원
- **동적 날씨 배경 테마 & 라이트/다크 모드**: 현재 기상 상태(맑음, 비, 눈, 흐림 등)와 주야간(`is_day`)에 따라 배경 그라데이션이 자동으로 변화하며, 기본 라이트 모드 및 다크 모드 토글 지원

## 📡 데이터는 어떻게 가져오나요 (외부 API 아키텍처)

- **Open-Meteo API의 특징**:
  - 비상업적 용도로 완전 무료이며, **API Key 발급 및 인증 헤더가 전혀 필요 없는 완전 공개(Public) RESTful API**입니다.
  - 복잡한 가입 절차 없이 위도(`latitude`)와 경도(`longitude`) 좌표 파라미터만으로 기상 관측소 네트워크 데이터를 즉시 조회할 수 있습니다.
- **UI 컴포넌트와 API 통신 로직(`src/api/weather.js`) 분리 이유 (Decoupling)**:
  - React UI 컴포넌트(`App.jsx` 등)에 `fetch` URL과 쿼리스트링 조립, 에러 핸들링 코드가 뒤섞이면 컴포넌트의 가독성과 재사용성이 크게 떨어집니다.
  - API 통신 레이어를 별도 모듈(`weather.js`)로 격리함으로써 엔드포인트 URL 변경이나 데이터 가공 로직 수정 시 UI 코드에 영향을 주지 않는 **관심사의 분리(Separation of Concerns)**를 실현했습니다.
- **도시 검색 시 디바운스(Debounce, 400ms)의 필요성**:
  - 검색창에 `Seoul`을 입력할 때 한 글자 타이핑마다 즉시 네트워크 요청을 보내면 `S`, `Se`, `Seo`, `Seou`, `Seoul` 총 5번의 불필요한 API 요청이 발생합니다.
  - 이는 사용자의 네트워크 트래픽을 낭비할 뿐만 아니라 Open-Meteo 서버에 DoS 형태의 부하를 유발하여 `HTTP 429 Too Many Requests`로 IP 차단을 당할 수 있습니다.
  - 400ms 디바운스 타이머를 적용하여 사용자의 타이핑이 멈춘 뒤에만 1회 호출되도록 보호했습니다.

## 🛡️ 보안에서 확인한 것 (사이버보안과 체크포인트)

- **Public API vs Private/Secret API (키 분리와 보안)**:
  - Open-Meteo처럼 공개된 기상 정보는 프론트엔드에서 직접 호출해도 무방하지만, 결제 API나 회원 개인정보, 유료 과금 API처럼 **비밀 키(Secret Key)**가 필요한 서비스는 결코 React 소스코드나 `.env`에 키를 넣어서는 안 됩니다.
  - 브라우저의 개발자 도구(Network 탭) 및 빌드된 자바스크립트 파일은 누구나 열어볼 수 있으므로, 클라이언트에 비밀 키를 심는 순간 100% 유출 사고로 이어집니다.
- **백엔드 프록시(BFF, Backend For Frontend)의 필수성**:
  - 비밀 키 보호와 권한 검증을 위해 반드시 자체 백엔드 서버(Node.js, Express, Next.js API Routes 등)를 구축하고, 비밀 키는 서버 측 환경변수에 숨겨두어야 합니다.
  - 클라이언트는 자체 백엔드와 세션/인증 토큰으로 통신하고, 백엔드가 외부 API를 대신 호출하는 프록시 아키텍처가 필수적입니다.
- **HTTPS 혼합 콘텐츠(Mixed Content) 방어**:
  - 현대 브라우저는 배포된 사이트(`https://`)가 안전하지 않은 비암호화 통신(`http://`)으로 리소스나 API를 요청하는 것을 강제로 차단(Blocked Mixed Content)합니다.
  - 중간자 공격(MitM)을 통한 패킷 도청과 데이터 위변조를 막기 위해 모든 외부 엔드포인트는 HTTPS 암호화 채널을 사용해야 합니다.

## 🎨 커스터마이징한 부분

1. **라이트/다크 모드 지원 (기본값: 라이트 모드)**:
   - 상단 우측에 Sun/Moon 아이콘 토글 스위치를 배치하여 원클릭으로 모드를 전환할 수 있습니다.
   - 사용자가 선택한 테마 모드는 브라우저 `localStorage`('weather_theme_mode')에 저장되어 새로고침 후에도 유지됩니다.
2. **실시간 기상 상태별 자동 배경 이미지 & 다층 그라데이션 테마**:
   - WMO 날씨 코드 및 주야간(`is_day`) 파라미터를 실시간 분석하여 대시보드 전체 배경에 날씨 분위기를 자동 반영합니다:
     - ☀️ **맑은 낮 (`weather-theme-clear-day`)**: 화사한 스카이블루와 따스한 골드 선샤인
     - 🌙 **맑은 밤 (`weather-theme-clear-night`)**: 깊은 미드나잇 네이비 & 달빛 인디고
     - ☁️ **구름 (`weather-theme-clouds-day / night`)**: 부드러운 펄 그레이 & 슬레이트 블루
     - 🌧️ **비 / 소나기 (`weather-theme-rain`)**: 촉촉한 아쿠아 블루와 빗줄기 앰비언스
     - ❄️ **눈 / 폭설 (`weather-theme-snow`)**: 순백의 파스텔 아이스 블루 & 프로스트
     - 🌫️ **안개 (`weather-theme-fog`)**: 몽환적인 실버 미스트
     - ⚡ **뇌우 (`weather-theme-thunder`)**: 일렉트릭 바이올렛 & 다크 림
3. **글래스모피즘(Glassmorphism) 카드 디자인**:
   - 모든 대시보드 카드에 반투명 배경과 `backdrop-filter: blur(18px)`를 적용하여, 배경의 역동적인 기상 그래픽이 은은하게 비치면서도 본문 텍스트는 선명하게 읽히도록 시각적 완성도를 극대화했습니다.
